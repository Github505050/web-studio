BEFORE & AFTER LAB

See the difference in a controlled environment.

Toggle each sample between its intentionally flawed and corrected states. These issues are isolated to the examples, not the website.

DEMO 01

Broken layout

Before: overlapping cards and awkward offsets. After: a balanced, flexible grid.

Broken layout demonstration
Problem: Misaligned margins and compressed gaps
Correction: Use gap-based flex layout and normal element flow.
Before: the deliberately flawed demonstration is active.
.cards { display:flex; gap:12px; }
DEMO 02

Mobile overflow

Before: a row becomes wider than its container. After: cards wrap correctly.

Mobile overflow demonstration
Problem: Fixed widths push content beyond the viewport
Correction: Use flex-wrap and flexible card widths.
Before: the deliberately flawed demonstration is active.
.cards { display:flex; flex-wrap:wrap; }
DEMO 03

JavaScript button

Before: a sample action has no connected behavior. After: it gives immediate feedback.

Contact interaction example

The example button is unresponsive in this state.

Problem: Missing click handler
Correction: Attach an event listener and update a status element.
Before: the deliberately flawed demonstration is active.
button.addEventListener("click", showFeedback);
DEMO 04

Inconsistent CSS

Before: clashing fonts, inconsistent alignment and poor contrast. After: coordinated visual design.

Inconsistent CSS demonstration
Problem: Scattered styles without shared tokens
Correction: Apply consistent type, spacing and color variables.
Before: the deliberately flawed demonstration is active.
.card { color:var(--ink); gap:12px; }
METHOD & QUALITY

Diagnose the cause. Fix the behavior.

A useful frontend repair should remain understandable and stable after the visible symptom disappears.

Reproduce

Understand the exact device, steps and expected behavior.

Isolate & correct

Make a targeted, reviewable change instead of masking symptoms.

Retest

Check the original problem and related responsive states.
