INDEPENDENT PORTFOLIO PROJECT

Mon Espace Français — French Classroom

A self-directed French-learning classroom with student activities and a separate teacher reporting workspace.

Objective: Students can access lessons, practice materials, saved work and progress. An authorized teacher dashboard summarizes learning activity.

Technologies: HTML, CSS, JavaScript, Firebase Authentication and Firestore

Functionality and limits: Student and teacher interfaces, weekly learning material, saved progress and responsive design. Teacher scores shown in the current project can be student-entered; this is not an automated handwriting grader.

INDEPENDENT PORTFOLIO PROJECT

Northline Supply — Support Chatbot

A fictional retail storefront designed to demonstrate a practical customer-support interface.

Objective: A guided FAQ assistant responds to sample questions and displays example order statuses using fictional data.

Technologies: HTML, CSS, JavaScript, structured FAQ knowledge base

Functionality and limits: Guided FAQ matching, sample order explanations, responsive storefront, suggested replies and fallback handling. A separate AI backend is optional and not active by default.
