Do I need any experience? +

No experience is assumed in this sample concept. Practice descriptions are designed to feel approachable, with options for different starting points.

Are these real classes I can book? +

No. Solace Studio is a fictional demonstration, and every class time is illustrative. There is no booking or payment feature.

Can I explore a class before choosing? +

Yes. Use the schedule filters and click “Details” beside any class to read its sample description.
